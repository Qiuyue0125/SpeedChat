
本项目实现了一个基于 Qt 6.7.3 和 MySQL 的即时通讯（IM）聊天软件，包含服务端（server/）和客户端（user/）两部分。
另外本项目不允许商用。
演示视频：https://www.bilibili.com/video/BV1tTXhBaEo3/?share_source=copy_web&vd_source=83b5ce34c8d8f6e4acce3fac19eb7f81

主要功能：
- 账号系统：用户注册、登录、密码找回（密保验证）、修改密码、注销账号
- 自动登录、记住密码，登录历史展示（含头像）
- 好友管理：搜索用户、添加好友、处理好友申请、删除好友、查看好友资料
- 即时通讯：文字消息、图片消息、文件传输、语音消息（录音/播放）
- 消息状态：未读计数、消息已读回执（ACK确认）
- AI 智能分析：对接 OpenAI 兼容 API（如 DeepSeek），可按时间范围分析聊天记录
- 云盘：文件上传（分片上传）、下载、搜索、我的文件列表展示、进度与速率显示
- 个人资料修改：昵称、性别、个性签名、头像上传与裁剪
- 主题定制：支持自定义应用背景和聊天背景
- 系统托盘：最小化到托盘、托盘消息提示
- 本地数据库：基于 SQLite 缓存聊天记录、好友列表，支持离线查看历史消息
- 网络层：自定义 TCP 协议、心跳保活、断线自动重连、离线/在线状态切换
- 安全：密码 SHA-256 + 盐值加密存储，登录凭据 DPAPI 加密保存

服务端特性：
- 多线程架构：线程池（ThreadPool）搭配数据库连接池（ConnectionPool）
- 消息路由：客户端间消息实时转发，支持批量转发优化
- 文件管理中转：分片上传与下载，支持限速控制
- AI 代理：转发客户端的 AI 分析请求至外部大模型 API
- 反压与限流：可配置的包速率限制、背压丢弃策略，防止恶意请求
- 日志系统：支持按级别、文件大小轮转、性能指标采样记录
- 优雅关闭：信号处理、资源清理，支持 AppImage 打包部署

-----

1. qt版本使用 6.7.3，不确定在别的版本上能否运行。
   - 客户端使用了 QWebEngine，但为条件编译。
   - 如果没有 QWebEngine 也可以启动程序。
   - 需要使用该模块请自行查找资料并导入 QWebEngine。

2. 如果缺失 MySQL 驱动请去：
   https://github.com/thecodemonkey86/qt_mysql_driver/releases?page=1
   下载。
   - 本项目 MySQL 使用 8.0 版本。
   - 运行前请检查配置文件和数据库连接信息是否正确。
